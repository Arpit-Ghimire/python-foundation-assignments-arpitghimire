# Day 1: Python Foundations

## Topics Covered

* Variables
* Data types
* String methods
* Operators
* Conditional statements

## Exercises

1. Sales Summary
2. Data Quality Checker
3. File Validator
4. Customer Record Cleaner
5. Pipeline Health Status
6. Dataset Access Decision (Stretch Exercise)

## How to Run

Run any exercise using Python from the terminal:

```bash
python exercise-01-sales-summary.py
```

Replace the filename with the exercise you want to run.

## What I Learned

Through these exercises, I gained hands-on experience with Python fundamentals, including variables, data types, arithmetic operations, string methods, conditional statements, and user input. I also learned how to organize code into separate files and write cleaner, more readable programs using meaningful variable names and comments.

## Challenges Faced

One challenge was deciding the correct conditions for classifying data and pipeline status, especially when multiple conditions needed to be checked together. I solved this by carefully analyzing the requirements and using `if`, `elif`, and `else` statements with logical operators such as `and` and `or`.
