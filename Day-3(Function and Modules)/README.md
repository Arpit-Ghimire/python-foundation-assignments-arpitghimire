# Functions and Modules Assignment

This assignment focuses on the fundamentals of **Python Functions and Modules**.

## Topics Covered

- Default arguments
- `*args`
- Multiple return values
- Built-in functions
- Global variables and the `global` keyword
- Creating and importing custom modules
- `random` module
- `datetime` module

## Questions

1. Simple Interest Calculator
2. Class Average using `*args`
3. Analyze Numbers
4. Shared Booking Counter
5. Temperature Report using a Custom Module

## Challenges

- Understanding how default arguments work when some arguments are not provided.
- Understanding how `*args` allows a function to accept any number of arguments.
- Returning and unpacking multiple values from a function.
- Understanding variable scope and why the `global` keyword is needed.
- Creating a separate Python module and importing it into another file.
- Working with standard Python modules such as `random` and `datetime`.

## Learnings

Through this assignment, I learned how to:

- Create functions with default parameters.
- Handle a variable number of arguments using `*args`.
- Return multiple values from a function.
- Use Python's built-in functions effectively.
- Understand the difference between local and global variables.
- Create and use custom Python modules.
- Use `random` to generate random values.
- Use `datetime` to work with dates and format them.
